A focused browser interface layer.

Version 0.3.2 targets browser games with React 19.3.1 and WebGL 1. It supports menus, HUDs and inventories. Text uses pre-baked glyph atlases and greedy wrapping; complex-script shaping, editable canvas text and native engine bindings remain outside the current renderer. Controller adapters can use the root’s focus navigation methods. The accessibility mirror covers pressable controls and live announcements, not full document semantics. Read the production support matrix before choosing it for a project.

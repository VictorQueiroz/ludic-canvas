Diagnostics and test conditions


Pause drawing to check movement of already-painted tiles. Fast scrolling can outrun the bounded tile cache and expose unpainted areas while paused. The JavaScript button schedules a deliberate 250 ms block: press it, then flick a list.


This is a rendering prototype, not an available ScrollArea or VirtualList backend. Tile copying may stall internally; timings measure JavaScript calls, not GPU completion or presentation. All 100 Yoga rows and native item buttons are retained. Nested scrolling, arbitrary overlapping layers, editors and virtualized collections are not qualified by this experiment.

TEXT / POINTER AND CLIPBOARD

Select the text you see.

Drag across canvas text. Double click a word, triple click a paragraph, or Shift click to extend. Ctrl/Cmd+A selects the focused canvas; Ctrl/Cmd+C copies. Try either independent root and paste below.

Plain Text is selectable by default. Set userSelect="none" to opt out, userSelect="all" for an atomic reference, or userSelect="text" to opt a control label in. Native fields retain their own editing selection. Touch long press selects a word and exposes draggable endpoints; physical phone behavior is not yet qualified.

Selection follows the atlas renderer's current typography limits: horizontal left-to-right text, without complex shaping or bidi. Copy uses displayed uppercase text, omits rich-text delimiters and hidden truncation, preserves source whitespace across soft wraps, and inserts a newline between Text elements. Virtualized lists expose mounted text only. This browser adapter does not add native-host selection, HTML clipboard data, text drag-and-drop, a mobile system menu, or full Chromium parity.

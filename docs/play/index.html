One game loop. Two canvases.

The application owns flight, cargo, collisions, and the Canvas 2D world. A transparent Ludic Canvas overlay owns the React HUD. The loop advances the simulation, draws the world, then calls ui.frame(now). React reads snapshots at 10 Hz; the ship keeps moving at the display refresh rate.

Two fonts. Separate modules.

The interface module defines Oxanium for headings and controls. The mission module defines Space Mono for telemetry and cargo. Each has its own font configuration and generated atlas. The root combines their FontSource exports. Run npm run fonts:game to regenerate both with the bundled CLI.

Resize the mission.

Try Compact layout or resize your window. Nested flex rows, progress bars and tabbed cargo panels become a narrow HUD with an on-demand manifest. ResizeObserver gives the game camera and UI the same dimensions. Pause menus block background controls, and Tab/Enter use the library's accessibility mirror.

ONE CONTRACT / YOUR DESIGN

State flows in. Requests flow out.

These are React components built from the four primitives. They do not install a theme or keep a second copy of your game state. A change callback asks the owner to update the next prop. Plain text belongs inside Text; use children or render functions to compose any appearance.

Button and Switch

Pointer activation, Enter and Space use the same callback. Disabled controls block activation. A switch reports its checked state to assistive technology. Supply your own layout, hover/press styles and content.

Switch API →

Slider

A horizontal slider owns primary-pointer capture, cancellation, min/max clamping and step snapping. Arrows change one step, Page Up/Down ten steps, and Home/End the endpoints. Its render function receives value, ratio and dragging. Cancellation never calls onValueCommit.

Slider API →

Tabs and Tab

Tabs groups controlled Tab components into one keyboard Tab stop. Arrows activate and focus adjacent enabled entries; Home/End jump to the ends. Choose horizontal or vertical navigation. Render the corresponding content from your controlled value; this component does not create tab panels.

Tabs API →

Dialog

The owner controls open. While visible, the topmost dialog isolates background input, traps Tab and requests Escape dismissal. Closing restores focus. Style the scrim and compose a panel and close button yourself. Disable Escape dismissal for a mandatory briefing or result screen.

Dialog API →

ScrollArea

A named vertical scroll region with wheel/touch scrolling and automatic reveal of focused controls. Give it a constrained height and content that can exceed it. Rendering remains eager; this is not a virtualized list.

ScrollArea API →

TextInput and TextArea

Choose Edit profile in either preview to try single-line and multiline native editing inside a scrolling dialog. Yoga positions the box and WebGL decorates it; native controls draw text, selection and caret. Fields share root-local focus and modal isolation. Native fields are unreleased in npm 0.6.0.

Native editing guide →

VirtualList

A bounded window for fixed-height single-select collections. Stable keys preserve logical focus and selection; typed handles scroll and focus distant items through the owning game loop. Rows support custom visual layouts, disabled states and logical position/size metadata.

Collection guide →

useUIRoot

Components can focus a stable control identifier through their owning root. Every createUI().render() supplies its own React context. The two previews deliberately reuse control identifiers while retaining separate focus and resource ownership.

Root hook API →

Compose a modal without coupling it to the game.

The dialog manages UI input. Your application decides whether opening it also pauses simulation, audio or networking.
